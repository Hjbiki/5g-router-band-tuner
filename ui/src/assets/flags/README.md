# Language flags

A flag here is named by language code: `en.svg`, `ar.svg`. It appears beside that language on the first-run screen, matched by name in `ui/src/lib/i18n/index.ts`. A language without a file shows its name alone and works the same.

A flag stands for a language here, not for a country: English has the United Kingdom's flag, and Arabic has Saudi Arabia's.

## Where the files came from

Both are from [flag-icons](https://github.com/lipis/flag-icons) 7.6.0 (the `4x3` set), fetched on 2026-11-14 and used as downloaded, under the MIT License in `LICENSE` beside this file.

| File | File in flag-icons |
| --- | --- |
| `en.svg` | `flags/4x3/gb.svg` |
| `ar.svg` | `flags/4x3/sa.svg` |

Keep them as they are. The Saudi flag carries the shahada: never mirror, crop or recolour it, and show it only through an `<img>`.
