# Operator logos

A logo here is named by operator id: `zain`, `stc` or `mobily`, as `.svg`, `.png` or `.webp`. It appears automatically, matched by PLMN code in `ui/src/lib/operators.ts`. A new operator also needs its PLMN code added there.

The logos are trademarks of their operators. The app shows one only to say which operator a SIM belongs to, and the project isn't affiliated with or endorsed by any of them. Without a file, the app shows that operator's name with a plain icon and works the same.
